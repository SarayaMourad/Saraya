# Saraya Premium Mobile V4

This version extends the premium redesign to mobile without changing Saraya's backend/business rules.

## Mobile changes
- Floating glass bottom navigation with active-page surface.
- Safe-area support for modern phones.
- Mobile app-shell background and translucent sticky headers.
- Redesigned chat composer as a floating input surface.
- More readable chat spacing and message bubbles.
- `/recette` cards resized for mobile with touch-friendly actions.
- Horizontal data tables remain scrollable instead of being crushed.
- Bottom-sheet dialogs now have blur, grab handle, safe-area padding and a usable maximum height.
- Stock/settings cards use larger touch targets and mobile card styling.
- Extra handling for narrow phones (380px and below).

No backend, Prisma, Gemini, analytics, stock, recette calculation or database logic was changed in this mobile pass.
